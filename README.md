# PP_TP2_51898
Entrega del segundo trabajo de Paradigmas de la programación del 2026


El trabajo tiene la posibilidad de crear estudiantes, salas, eventos y actividades con el propósito de organizar inscripciones a los eventos propios y manejar costos y ganancias posibles.
Permite buscar información sobre actividades particulares a través del uso de un filtro y el uso de la función mostrarDatos().

También implementa la prevención de excepciones haciendo uso de sistemas try-catch no solo en el main, sino también en las funciones relevantes en cada clase.

Finalmente, dá la opción de persistir cada evento nuevo creado con el uso de persistirEvento():
